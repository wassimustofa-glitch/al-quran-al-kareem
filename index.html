About

Al-Quran Al-Kareem

Version 2.0.0

A beautiful, feature-rich Quran reading experience

Developer

Wassi

Full-Stack Developer & Designer

Passionate about creating beautiful Islamic applications

Features

  • Complete Quran with 114 Surahs
  • Arabic, English & Bangla translations
  • Multiple renowned reciters
  • Bookmarks & personal notes
  • Reading progress tracking
  • Prayer times & Qibla direction
  • Digital Tasbih counter
  • Islamic (Hijri) calendar
  • Daily duas collection
  • Multiple themes & customization
  • Keyboard shortcuts
  • Offline support

Data Sources

  • Quran text: Al-Quran Cloud API
  • Translations: Sahih International, Muhiuddin Khan
  • Audio: Multiple renowned reciters
  • Prayer times: Aladhan API

Technologies

HTML5 CSS3 JavaScript REST APIs LocalStorage Web Audio Geolocation PWA Ready
